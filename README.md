# ハロコレ URL保存サポーター v6

スマホでハロコレ/ORICALの `frontimage` URLを貼り付けて、単体画像・単体動画の保存補助、連番候補の検出、URL一覧コピー、ZIP作成を行うWebアプリです。

## v6の変更点

- 開始URLと終了URLを入れ替えるボタンを追加
- 最初の注意書きセクションを削除
- 「詳細ページからURLを拾う補助」セクションを削除
- 検出結果の番号を 2 に変更
- v5の動画メタデータ現在時刻化、開く前の状態保存は維持

## 更新方法

既存のWebアプリのファイルを、このフォルダの中身で全部置き換えてください。
スマホで古い画面が残る場合は、URL末尾に以下を付けて開いてください。

```text
?v=6
```

例：

```text
https://自分の公開URL/index.html?v=6
```

PWAとしてホーム画面に追加している場合、古い版を掴み続けることがあります。その場合はホーム画面アイコンを一度削除して、最新版を開いた状態でもう一度追加してください。

## 使い方

1. 開始カードURLに `frontimage` の画像/動画URLを貼る
2. 単体保存なら終了カードURLは空欄のまま
3. 連番検出なら終了カードURLにもURLを貼る
4. 逆に入れてしまった場合は「開始URLと終了URLを入れ替え」を押す
5. 「候補を検出 / 単体追加」を押す
6. 検出結果から「コピー」「開く」「保存」「共有保存」を使う

動画を写真アプリに保存したい場合は、共有シートで「ビデオを保存」を選んでください。ファイルアプリに保存したい場合は「ファイルに保存」を選んでください。
