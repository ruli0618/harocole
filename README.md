# ハロコレ URL保存サポーター v9

## v9の変更点

- クリップボードから開始URLへ貼り付けるボタンを追加
- クリップボードから終了URLへ貼り付けるボタンを追加
- 既存の入力内容は削除してから貼り付ける仕様に変更
- 「貼り付けて検出」ボタンを追加
- 複数行/複数URLを、先頭=開始URL・最後=終了URLへ分けるボタンを追加
- v8までの機能は維持

## 更新後

公開先URLの末尾に `?v=9` を付けて開いてください。
古いホーム画面アイコンが残る場合は一度削除して、最新版を開いてから追加し直してください。

## クリップボード貼り付けについて

HTTPS上、またはホーム画面に追加したPWA上で、ボタン操作として実行してください。
端末やブラウザによっては貼り付け許可が表示されることがあります。
自動読み取りできない場合は、入力ダイアログに手動貼り付けしてください。
