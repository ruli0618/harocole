# ハロコレ 画像保存サポーター v11

## 追加内容

- iPhoneショートカット導入補助を追加
- ショートカット用JavaScriptコードを1タップコピー
- 設定手順を1タップコピー
- ショートカットアプリを開くボタンを追加
- iCloudショートカット共有リンクを登録できる欄を追加

## 配布時のおすすめ

一番簡単にするには、完成済みショートカットをiPhoneのショートカットアプリから共有し、iCloudショートカットリンクを作成します。
そのリンクをアプリ内の「配布用の1タップ追加リンクを登録」に入れると、アプリ上に「ショートカットを追加」ボタンが表示されます。

配布用に全員へ固定表示したい場合は、`app.js` の `SHORTCUT_INSTALL_URL` にiCloudリンクを入れてください。

## 更新

公開後は `?v=11` を付けて開いてください。古いPWAが残る場合はホーム画面アイコンを削除して追加し直してください。
