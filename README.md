# ハロコレ 画像保存サポーター v15

## 追加内容

- 検出結果に「複数一括保存」ボタンを追加
- 複数の画像/動画を取得して、共有シートへまとめて渡せるように変更
- 共有一括保存が使えない環境向けに「個別保存を連続実行」ボタンを追加
- ZIP作成、URLコピー、共有、v14までの機能は維持

## 注意

- iPhone/Safariでは、完全な無確認一括保存はできません。共有シートで「ビデオを保存」または「ファイルに保存」を選んでください。
- 件数や動画サイズが大きいと、iOS側で共有シートが開けないことがあります。その場合は件数を減らすかZIP作成を使ってください。

## 更新

公開後は `?v=15` を付けて開いてください。古いPWAが残る場合はホーム画面アイコンを削除して追加し直してください。

## アイコンについて

今回の更新ZIPにはアイコンファイルを含めていません。既存のアイコンファイルはそのままサーバー上に残して使ってください。
