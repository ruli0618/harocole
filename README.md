# ハロコレ 画像保存サポーター v17

スマホ向けのハロコレ/ORICAL保存補助Webアプリです。

## v17の変更点

- 「開始URLから自動連番検索」を追加
- 終了URLを入れなくても、開始URLの番号から順番に候補を確認できます
- ★1〜★5 / jpg・mp4 / 枝番 `_1` / `_2` を確認し、見つからない番号が続いた所で自動停止します
- 停止条件を「1件 / 2件 / 3件 / 5件連続未検出」から選べます
- 最大確認数を指定できます
- v16までの分割一括保存・ショートカット追加・ハロコレを開く機能は維持
- アイコンファイルは含めていません

## 更新方法

既存の配置先に、このZIP内のファイルを上書きしてください。

更新後はスマホで `?v=17` を付けて開いてください。

例: `https://example.com/index.html?v=17`

## 使い方

### 終了URLありの場合

1. 開始URLと終了URLを貼り付ける
2. 「候補を検出 / 単体追加」を押す

### 終了URLなしで自動検索する場合

1. 開始URLだけを貼り付ける
2. 「未検出が続いたら停止」を選ぶ
   - 完全に連続しているなら「1件で停止」
   - 途中で抜けがありそうなら「3件連続で停止」がおすすめです
3. 必要なら最大確認数を調整する
4. 「開始URLから自動連番検索」を押す

※ 自動検索は、開始URLと同じURL構造・同じコードで番号だけが増えていくパターンを確認します。
