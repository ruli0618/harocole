# ハロコレ URL保存サポーター PWA

スマホ向けのハロコレ/ORICALカードURL検出・保存補助Webアプリです。

## 今回の変更

- 終了URLが空欄でも動く「単体モード」を追加
  - 開始URLに mp4 / jpg などの `frontimage` URLを1つ貼るだけで保存対象にできます
  - 開始URL欄に複数URLを貼った場合は、その分をまとめて追加します
- 動画の「保存」ボタンをiPhone向けに変更
  - mp4の場合は再生ページを開くのではなく、先にファイルとして取得して共有シートを開きます
  - 共有シートから「ビデオを保存」または「ファイルに保存」を選んでください
- キャッシュ対策を強化
  - Service Workerを v3 に更新
  - 同一ドメインのファイルはネットワーク優先で読み込みます

## 使い方

1. `index.html`, `app.js`, `style.css` などを GitHub Pages / Cloudflare Pages 等にアップロード
2. スマホで開く
3. 単体保存したい場合は「開始カードURL」だけに動画URLを貼って「候補を検出 / 単体追加」
4. 連番検出したい場合は「開始カードURL」と「終了カードURL」の両方を入れて検出
5. 動画は「動画保存」または「共有保存」を押し、共有シートで保存先を選んでください

## 注意

WebアプリはChrome拡張と違い、他サイトにボタンを直接差し込めません。
また、iPhone SafariはWebページから写真アプリへ完全自動で動画保存することを許可していません。
そのため、このアプリでは動画をファイル化して共有シートへ渡す方式にしています。


## v4 追加修正

- 「開く」で動画/画像を再生して戻った時、検出結果・入力内容を自動復元します。
- 検出結果はブラウザのローカル保存に残るため、ページが再読み込みされても復帰できます。
- 「入力をクリア」を押すと、入力内容と検出結果の保存も削除します。
- 保存/共有保存/ZIP作成時は、Webアプリ側で取得し直したファイルに現在時刻の更新日時を付けます。

### タイムスタンプについて

Webアプリ側では `File.lastModified` とZIP内の日付を現在時刻にしています。iPhoneの写真アプリが動画内部のメタデータを優先する場合、写真アプリ上の並び順だけは元動画の日付に見えることがあります。その場合は「ファイルに保存」を使う方が更新日時を確認しやすいです。


## v5 追加修正

- MP4保存/共有保存/ZIP作成時に、動画ファイル内部の `mvhd` / `tkhd` / `mdhd` の作成日時・更新日時を現在時刻へ書き換える処理を追加しました。
- iPhoneの写真アプリが動画内部メタデータを優先して古い日付で並べる問題への対策です。
- ただし、動画によっては別形式の撮影日時メタデータを写真アプリが優先する場合があります。その場合はiOSショートカットの「メディアをエンコード」などで再エンコード/再保存する必要があります。
