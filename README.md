# ハロコレ URL保存サポーター v7

スマホでハロコレ/ORICALの `frontimage` URLを貼り付けて、単体画像・単体動画の保存補助、連番候補の検出、URL一覧コピー、ZIP作成を行うWebアプリです。

## v7の変更点

- 「ハロコレを開く」ボタンを追加
- ボタンから `https://helloproject.orical.jp/mypage/Ruliiiimaepiiii` を新しいタブ/画面で開く
- 開く前に入力内容と検出結果を保存
- v6の開始/終了URL入れ替え、動画メタデータ現在時刻化、開く前の状態保存は維持

## 更新方法

既存のWebアプリのファイルを、このフォルダの中身で全部置き換えてください。
スマホで古い画面が残る場合は、URL末尾に以下を付けて開いてください。

```text
?v=7
```

例：

```text
https://自分の公開URL/index.html?v=7
```

PWAとしてホーム画面に追加している場合、古い版を掴み続けることがあります。その場合はホーム画面アイコンを一度削除して、最新版を開いた状態でもう一度追加してください。

## 使い方

1. 「ハロコレを開く」で対象ページを開く
2. ショートカットなどで `frontimage` の画像/動画URLをコピーする
3. Webアプリに戻って開始カードURLに貼る
4. 単体保存なら終了カードURLは空欄のまま
5. 連番検出なら終了カードURLにもURLを貼る
6. 逆に入れてしまった場合は「開始URLと終了URLを入れ替え」を押す
7. 「候補を検出 / 単体追加」を押す
8. 検出結果から「コピー」「開く」「保存」「共有保存」を使う

動画を写真アプリに保存したい場合は、共有シートで「ビデオを保存」を選んでください。ファイルアプリに保存したい場合は「ファイルに保存」を選んでください。
