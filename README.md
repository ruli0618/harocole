# ハロコレ 画像保存サポーター v13

## 追加内容

- 「ハロコレを開く」先を特定アカウントURLから共通マイページURLへ変更
- 空欄なら `https://helloproject.orical.jp/mypage` を開くように変更
- 必要な場合だけ、各端末ごとに自分専用のハロコレURLを保存できる設定欄を追加
- クリップボードからハロコレURLを設定するボタンを追加
- v12のショートカット埋め込み・検出・保存・貼り付け機能は維持

## 更新

公開後は `?v=13` を付けて開いてください。古いPWAが残る場合はホーム画面アイコンを削除して追加し直してください。

## アイコンについて

今回の更新ZIPにはアイコンファイルを含めていません。既存のアイコンファイルはそのままサーバー上に残して使ってください。
