# ハロコレ 画像保存サポーター v14

## 追加内容

- 「ハロコレを開く」設定とボタンを下側の専用セクションへ移動
- 「ショートカットを追加」セクションを一番下へ移動
- よく使う「候補を検出 / 単体追加」をURL入力欄の直後に近い位置へ整理
- 検出結果をその下に表示する順番へ変更
- v13の共通マイページURL設定、ショートカット埋め込み、保存・貼り付け機能は維持

## 更新

公開後は `?v=14` を付けて開いてください。古いPWAが残る場合はホーム画面アイコンを削除して追加し直してください。

## アイコンについて

今回の更新ZIPにはアイコンファイルを含めていません。既存のアイコンファイルはそのままサーバー上に残して使ってください。
